# Kalkulator Modern

Kalkulator responsif menggunakan:
- HTML5
- CSS3
- JavaScript vanilla

Fitur:
- Operasi +, -, ×, ÷
- Persentase
- Desimal
- AC dan DEL
- Keyboard support
- Dark/light mode
- Tampilan responsif
- Tidak membutuhkan library eksternal

Cara menjalankan:
1. Buka `index.html` di browser.
2. Atau gunakan Live Server di VS Code.
